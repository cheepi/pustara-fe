Overview

Pustara FE itu web app utama untuk user-facing experience.

App Router

Routing utama ada di `src/app`, termasuk login, katalog, profil, baca buku, dan halaman komunitas.

Auth flow

Firebase Client SDK dipakai di frontend, lalu token dikirim ke backend buat verifikasi sesi dan akses data.

Motion & polish

Framer Motion dipakai buat transisi halus, sementara komponen visual utama tetap konsisten dengan tema lama.

Flow

02 Token ke backend

03 Render experience

Halaman utama, katalog, dan reader tampil dengan navigasi yang cepat dan stabil.

Deploy

Cara publish docs ini ke GitHub Pages.

1. Buka repo `pustara-fe` di GitHub

2. Masuk ke `Settings` → `Pages`

3. Pilih `Deploy from a branch`

4. Set `Branch: main` dan `Folder: /docs`

Kalau sudah aktif, GitHub Pages bakal ambil file langsung dari folder `docs`.

Kalau mau aman dari file tersembunyi, `docs/.nojekyll` juga bisa ditambah.
